# Original User Request

## Initial Request — 2026-09-28T13:20:44Z

Пакет из 10 доработок и исправлений для Windows-версии `swch` (универсальный лаунчер и менеджер игровых библиотек/аккаунтов Steam, Epic Games, Riot Games). Реализация в текущей рабочей директории с использованием полной команды агентов.

Working directory: e:\swch
Integrity mode: development

## Requirements

### R1. Epic Games: открытие ссылки входа в браузере по умолчанию
- Ссылка авторизации («Войти в Epic Games») должна открываться во вкладке системного браузера пользователя по умолчанию (используя уже открытый браузер и его профиль), а не во встроенном WebView или отдельном изолированном окне.

### R2. Epic Games: поддержка игр в процессе обновления (Fortnite)
- Сканер каталогов манифестов EGS (`scan_manifest_directory`) должен сканировать не только корневой каталог `Data\Manifests`, но и подкаталог `Data\Manifests\Pending`.
- Игры с флагом `bIsIncompleteInstall: true` (например, обновляющийся Fortnite) не должны отбрасываться; они должны добавляться в библиотеку со статусом «Обновляется / Загружается».

### R3. Riot Games: полноценный Hot-Swap сессий и локальные постеры
- Реализовать сохранение текущей сессии Riot Client и переключение между аккаунтами через сохранение и подмену файлов конфигурации сессий (`%LOCALAPPDATA%\Riot Games\Riot Client\Data\RiotClientPrivateSettings.yaml` и связанных файлов сессий).
- Завершение процессов `RiotClientServices.exe` перед подменой файлов.
- Локальное подключение постеров для League of Legends, VALORANT и Legends of Runeterra из каталога `ui/artwork`.

### R4. Меню добавления аккаунтов: редизайн и структурирование
- Редизайн модального окна добавления и управления аккаунтами: разделение по вкладкам/категориям для каждого лаунчера (Steam, Epic, Riot, Roblox, Minecraft).
- Четкие индикаторы статуса для каждого лаунчера («Подключено», «Сессия сохранена», «Требуется авторизация»).
- Информативные подсказки, объясняющие, как работает подключение и зачем нужны токены/файлы сессий.

### R5. Сортировка игр в библиотеке по умолчанию
- Базовый порядок сортировки игр в библиотеке: 1) Сначала Избранное (`Favorites`), 2) Затем Установленные игры (`Installed`), 3) Затем по алфавиту (`A-Z`).

### R6. Карточка игры: стилизация постера в стиле Steam/Playnite
- Редизайн модального окна карточки игры: слева аккуратный вертикальный бокс-арт с пропорцией 2:3 без обрезки и искажений, справа — заголовок, метаданные, бейджи, стоимость и кнопка «Играть». На заднем плане — мягко размытый атмосферный арт игры.

### R7. Steam: персистентное безлимитное хранение аккаунтов
- swch должен хранить все когда-либо добавленные аккаунты Steam в локальной SQLite БД и каталоге `steam_sessions` без лимитов официального клиента Steam.
- При переключении на аккаунт, который был вытеснен из `loginusers.vdf`, swch автоматически восстанавливает его блок данных и sentry-файлы в `loginusers.vdf` и системный реестр перед запуском Steam.

### R8. Steam: устранение ошибки "Failed to switch" при первом клике
- Устранить race condition при переключении Steam: дожидаться гарантированного завершения процессов `steam.exe` и `steamwebhelper.exe` и освобождения дескрипторов файлов перед записью конфигураций.
- Добавить retry-логику при временных блокировках файлов, чтобы переключение срабатывало надежно с первого клика.

### R9. Epic Games: безопасный Switch без сохраненного профиля
- При попытке переключиться на аккаунт Epic, для которого еще не была сохранена локальная сессия, предотвратить холостое закрытие EGS: выводить информативное сообщение с предложением войти в этот аккаунт.
