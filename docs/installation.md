# Установка SWCH как приложения

Скачайте файлы из [GitHub Releases](https://github.com/Kabarab/swch/releases/latest).
Репозиторий приватный: для скачивания нужен аккаунт с доступом к нему.

## Windows

Запустите `SWCH-Setup-<версия>.exe`. Приложение установится для текущего пользователя
в `%LOCALAPPDATA%\Programs\SWCH`, без прав администратора. Появятся ярлык **SWCH**
в меню «Пуск» и запись в «Установленных приложениях». Ярлык на рабочем столе можно
выбрать при установке. У приложения, ярлыков и установщика используется выбранная
круглая иконка; идентификатор панели задач — `com.kabarab.swch`.

ZIP и `swch.exe` из него предназначены для запуска без установки. Для регистрации
в меню «Пуск» и списке установленных приложений используйте `SWCH-Setup-*.exe`.

## macOS 13.5 и новее, Apple Silicon

Откройте `SWCH-Setup-<версия>-arm64.pkg` и пройдите стандартный мастер macOS.
Он установит **SWCH.app** в `/Applications` («Программы»). Приложение имеет
идентификатор `com.kabarab.swch`, тип `APPL` и выбранную квадратную иконку
со скруглёнными углами. После установки оно регистрируется в LaunchServices
для Finder, Launchpad и поиска. Запускайте **SWCH** из «Программ» или Launchpad.
При установке в общую папку «Программы» macOS может запросить пароль администратора.

Подпись Developer ID и нотарификация Apple пока не настроены. Если macOS
блокирует установщик или первый запуск, проверьте, что файл скачан из этого
репозитория, и используйте «Открыть всё равно» в «Системные настройки →
Конфиденциальность и безопасность». Это стандартное подтверждение пользователя;
установщик не отключает защиту macOS. [Инструкция Apple](https://support.apple.com/en-ie/102445).

## Обновление и данные

Новый установщик обновляет приложение. Аккаунты, настройки и данные модов
хранятся отдельно от установленных бинарных файлов и сохраняются.

## Проверки сборки

GitHub Actions проверяет Windows-ярлык, AppUserModelID, запись удаления,
название и версию EXE, хеши установленных файлов, повторную установку и удаление.
На macOS проверяются установка в `/Applications/SWCH.app`, метаданные, ARM64, минимальная версия системы в бинарных файлах,
подпись целостности, регистрация LaunchServices, хеши файлов и сохранение данных
при повторной установке. Эти проверки запускаются только на изолированных CI runners.
