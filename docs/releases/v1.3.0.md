# SWCH 1.3.0

- Поддержка модов на JavaScript: темы, вкладки, действия и новые игровые платформы. Установка ZIP, режим разработки, обновление, перезапуск и откат; Node.js 24 включён в приложение.
- Каталог модов через GitHub Releases, SDK, CLI и примеры. На странице модов — краткий гайд и английский промпт для ИИ с кнопкой копирования.
- Выбор языка интерфейса, загрузка и кэш языковых пакетов, RTL и адаптация длинных подписей. В каталоге готовы 21 язык и вариант; машинные переводы отмечены. Остальные языки ещё не готовы.
- Новые интеграции GOG GALAXY, Ubisoft Connect и HoYoverse, обновлённое подключение Epic Games через браузерное расширение.
- Сохранение и переключение сессий игровых аккаунтов, улучшения Minecraft и Riot, исправления импорта библиотеки и обновляющихся игр Epic Games.
- Время в играх, статистика Deadlock и Riot, расширенные коллекции и фильтры инвентаря; обновлённые страницы аккаунтов и адаптивный интерфейс.
- Автоклеймер временных раздач: отдельная вкладка настроек, расписание, проверочный режим, история и очередь ключей. Вход и проверка магазина отделены от подтверждения получения игры.
- Настройки автозапуска Windows, улучшения запуска и работы нативных оболочек.

Сборки: Windows x64 и macOS ARM64. На Windows распакуй архив целиком и запускай `swch.exe`; на macOS распакуй `swch.app`. Не запускай серверный исполняемый файл вместо приложения.

Моды исполняются с правами пользователя. Автоматическая проверка каталога проверяет пакет и владельца репозитория, но не является проверкой безопасности кода.
