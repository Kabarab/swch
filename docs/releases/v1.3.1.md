# SWCH 1.3.1

- Windows: запускайте `SWCH-Setup-1.3.1.exe`. SWCH появится в меню «Пуск» и списке установленных приложений с собственной иконкой. У EXE есть название, версия и единый идентификатор панели задач.
- macOS 13.5 и новее, Apple Silicon: новый `SWCH-Setup-1.3.1-arm64.pkg` устанавливает `SWCH.app` в «Программы» и регистрирует приложение для Finder, Launchpad и поиска. Исправлена случайная зависимость интерфейса от macOS 26.
- Утверждённые иконки: круглая минималистичная для Windows, квадратная со скруглёнными углами для macOS; прозрачный внешний фон и размеры для Retina.
- В сборке проверяются реальные установки, запись приложения в системе, повторная установка и сохранение данных.

ZIP-архивы сохранены для ручной установки и встроенного обновления. Репозиторий и релиз остаются приватными.

На macOS подпись Developer ID и нотарификация пока не настроены: установка или первый запуск могут потребовать «Открыть всё равно» в настройках конфиденциальности и безопасности. Инструкция: https://support.apple.com/en-ie/102445.
