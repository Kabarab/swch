# SWCH 1.3.3

- Моды можно привязывать к играм и приложениям. Автор указывает общую привязку в манифесте при публикации, а пользователь при необходимости переопределяет её локально.
- Кнопка «Моды» в карточке игры открывает общий раздел с фильтром по этой игре. Расширение получает выбранную игру и публичные данные аккаунта.
- Добавлены поиск и фильтры модов по игре, типу, установке и совместимости, а также сортировка по названию и скачиваниям.
- В карточках модов показываются скачивания ZIP из стабильных релизов GitHub. Статистика обновляется вместе с каталогом; повторные загрузки тоже учитываются.
- Библиотека быстрее появляется при запуске благодаря локальному кэшу. Уточнены состояния загрузки, обновления и запуска игр Steam.
- Обновлены настройки запуска Windows, выбор цвета интерфейса и интерфейс мода автоклеймера.

Windows: установщик `SWCH-Setup-1.3.3.exe`. macOS 13.5 и новее, Apple Silicon: `SWCH-Setup-1.3.3-arm64.pkg`. ZIP-архивы доступны для ручного запуска и встроенного обновления.

Аккаунты, настройки и данные модов сохраняются при обновлении. Доступ к скачиванию определяется доступом к репозиторию.
