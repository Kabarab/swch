# SWCH 1.3.6

- Steam: устаревшие счётчики в файлах клиента больше не выдаются за текущие 0% и 0 МБ/с. При отсутствии точных данных показывается неопределённый прогресс; доступная скорость Steam отображается отдельно.
- Epic Games: перед прямым запуском проверяется установленная версия игры. Устаревшая или неподтверждённая версия не запускается; SWCH предлагает проверить обновления в Epic Games Launcher.
- Улучшены отображение загрузки обновлений SWCH и обработка ошибок скачивания.
- При первом запуске язык выбирается по системным настройкам; ручной выбор сохраняется. Обновлены диалог подключения аккаунтов и языковые пакеты. Новые строки без перевода в дополнительных языках пока отображаются на английском.
- Включены текущие изменения SDK модов и управления их файлами.

Windows: `SWCH-Setup-1.3.6.exe`. macOS Apple Silicon: `SWCH-Setup-1.3.6-arm64.pkg`. ZIP-архивы предназначены для ручного запуска и встроенного обновления.

Аккаунты, настройки и данные модов сохраняются при обновлении.
