# SWCH 1.3.2

- Исправлена иконка Windows в панели задач: маленькие размеры используют более крупные наконечники и широкие разрывы, чтобы две стрелки не сливались в обычное кольцо.
- Большой логотип Windows и выбранная иконка macOS сохранены.
- Windows: скачайте `SWCH-Setup-1.3.2.exe` и обновите установленное приложение. Если закреплённый ярлык продолжает показывать старую иконку, открепите его и закрепите заново после запуска SWCH.
- macOS 13.5 и новее, Apple Silicon: установщик `SWCH-Setup-1.3.2-arm64.pkg`. ZIP-архивы доступны для ручной установки и встроенного обновления.

Аккаунты, настройки и данные модов сохраняются при обновлении. Репозиторий и релиз остаются приватными; для скачивания нужен доступ к репозиторию.

Подпись Developer ID и нотарификация macOS пока не настроены. Инструкция для первого запуска: https://support.apple.com/en-ie/102445.
