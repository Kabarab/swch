# Языки SWCH

Основной и резервный язык приложения — **английский**. По умолчанию SWCH
выбирает системный язык при запуске. Если готового перевода нет или пакет
нельзя загрузить, интерфейс остаётся на английском. Русский и английский
входят в сборку; другим языкам для первой загрузки может понадобиться интернет.

Язык выбирается в **Настройки → Общие → Язык интерфейса**. Найди язык, выбери
его и нажми **Скачать и применить**. Перевод применяется ко всему окну после
загрузки и проверки пакета; при ошибке остаётся прежний язык. Метка
**Машинный перевод** означает, что точность не проверена носителями.

Первый пункт списка — **По умолчанию**, рядом указано название системного языка.
Этот режим следует системным настройкам при следующем запуске. Ручной выбор
конкретного языка сохраняется и имеет приоритет над системным. Существующий
сохранённый выбор, в том числе русский, после обновления не сбрасывается.

Сборка содержит русский и английский. Остальные готовые пакеты скачиваются
с публичной ветки `language-packs` в `Kabarab/swch`. GitHub раздаёт статические
JSON-файлы: отдельного сервера, API-ключа и оплаты переводчика не требуется.
Установленные пакеты сохраняются в IndexedDB и работают без интернета.
Выбранный пакет также хранится на диске SWCH: страницы входа в другом браузере
могут получить уже установленный перевод от локального API без доступа к GitHub.
Аккаунты, игровые названия, код, ID, введённые данные и английский промпт
для автора мода не переводятся и не отправляются переводчику.

На странице **Моды → Как создать и опубликовать мод** есть короткая инструкция
и копируемый английский промпт. Инструкция и подписи включены в каждый пакет.
SDK iframe стороннего мода локализует сам автор: SWCH не переписывает чужой DOM.

## Обновление переводов

`ui/lang/source.json` — инвентаризация текстов исходного интерфейса, включая
атрибуты доступности, уведомления, подтверждения и сообщения собственного
бэкенда. `locations` указывает файлы, из которых получена каждая строка.
Подстановки имеют вид `{0}`, `{1}`; перевод может менять их порядок, но не
удалять, добавлять или дублировать. Технические диагностические подробности
сторонних сервисов и код в журнале сохраняются как данные.

```powershell
./.graphify-tools/venv/Scripts/python.exe scripts/extract_i18n.py
# Только с согласия владельца на отправку открытых UI-строк Google:
./.graphify-tools/venv/Scripts/python.exe scripts/generate-language-packs.py --workers 2
node scripts/language-packs.mjs --check
# Полнота всех 249 пакетов (строгая проверка полного набора):
node scripts/language-packs.mjs --check --require-all
node --test tests/ui/i18n.test.mjs
cargo test --test i18n_tests
```

Генератор — необязательный инструмент разработчика, использующий бесплатный
веб-перевод Google. Это не поддерживаемый Cloud API: сервис может менять формат
и ограничивать запросы. Генератор соблюдает паузы, сохраняет промежуточные
результаты в `output/languages/checkpoints`, возобновляет работу и не публикует
неполные пакеты. Его каталог содержит 249 языков и вариантов из списка Google
Translate; это не все тысячи языков мира.

Пакеты допускают ручное редактирование. После исправлений запускай проверку
и пересчитывай индекс. Для воспроизводимых исправлений используй файлы
`ui/lang/overrides/<locale>.json`: объект исходных строк и исправленных переводов.
В списке выбора видны только полностью готовые пакеты текущей версии каталога.
Недоступность бесплатного переводчика не делает неполный пакет готовым.
Лаунчер обновляет каталог в фоне и сохраняет его для работы без интернета.
Новые языки и исправленные пакеты того же каталога исходных строк появляются
без пересборки SWCH; уже установленный перевод не меняется автоматически.

Workflow **Language packs** проверяет готовые файлы и публикует их в отдельную
ветку. Он не запускает переводчик. Файл хранится по пути
`<source-revision>/<locale>-<sha256>.json`, так что исправленный перевод
получает новый адрес. В релиз попадает индекс с контрольными суммами и только
два базовых пакета. Перед первым релизом запусти этот workflow после отправки
изменений на GitHub. Публикация требует стандартного `GITHUB_TOKEN` с правом
записи; пользовательские токены и платные сервисы не нужны.

Выбор языка также сохраняется локальным API в `<config-dir>/swch/i18n` вместе
с экранированными HTML-шаблонами для нативных экранов запуска/ошибок Windows
и macOS. Без сохранённого выбора используется системный язык с английским
резервным вариантом. Самые ранние нативные экраны до подключения бэкенда
используют встроенный русский для русской системы, иначе английский; после
применения пакета нативные экраны используют сохранённый перевод.
Выбор и все нативные шаблоны фиксируются одной атомарной сменой указателя
`active.txt`; при неудачной записи предыдущий набор остаётся активным.
Для тестов путь можно заменить переменной `SWCH_I18N_DIR`.

UI использует `lang`, `dir`, локальные форматы чисел/дат и правила переноса
длинных подписей. Проверки покрывают RTL, узкие окна, неполный пакет, неверный
SHA-256, кэш после перезапуска и копирование промпта.
