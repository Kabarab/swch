# GOG GALAXY

SWCH поддерживает несколько аккаунтов GOG и объединяет их купленные игры в одну библиотеку. Общая игра появляется один раз со всеми владельцами. Установки определяются отдельно от владения: локально установленная игра не становится собственностью всех аккаунтов.

## Подключение

1. Открой **Подключить аккаунт → GOG GALAXY**.
2. Нажми **Войти в GOG в браузере** и войди на сайте GOG. Пароль и второй фактор вводятся только на сайте GOG.
3. После перенаправления скопируй полный адрес страницы `on_login_success`, включая параметр `code`, и вставь его в SWCH. Можно вставить только код.
4. Нажми **Подключить аккаунт GOG**. SWCH получит имя аккаунта и синхронизирует библиотеку.

Для добавления другого аккаунта выйди из GOG в браузере и повтори процедуру. Данные доступа сохраняются в системном хранилище учётных данных (`swch:gog`), отдельно для каждого аккаунта. SWCH автоматически обновляет истёкший доступ при синхронизации. В SQLite находятся имена аккаунтов, игры и связи владельцев; пароли и токены туда не записываются.

## Библиотека и запуск

Выбери **GOG GALAXY** слева. Фильтр **Аккаунт GOG** показывает игры конкретного владельца. Кнопка **Синхронизировать GOG** обновляет выбранный аккаунт либо все аккаунты. Синхронизация также доступна в управлении аккаунтом. Сохранённая библиотека доступна после перезапуска и без сети. При ошибке загрузки списка игр предыдущая библиотека остаётся на месте; ошибка показывается пользователю.

На Windows SWCH обнаруживает GALAXY по реестру и стандартным папкам, а установленные игры — по реестру GOG, записям удаления и манифестам `goggame-*.info`. DLC с другим `rootGameId`, повреждённые манифесты и отсутствующие папки пропускаются. SWCH импортирует из GALAXY только игры GOG: игры других сервисов, подключённых к GALAXY, обслуживают соответствующие модули SWCH.

**Войти в GALAXY** переключает аккаунт в официальном клиенте на Windows. SWCH проверяет сохранённый доступ, закрывает клиент, передаёт сессию GALAXY и ждёт подтверждения входа. Метка **В GALAXY** отражает данные клиента, а фильтр **Аккаунт GOG** выбирает библиотеку для просмотра. Перед переключением заверши игру. Если клиент не подтвердит вход, SWCH восстановит прежние данные входа. Резервная копия предыдущей сессии хранится в системном хранилище `swch:gog:galaxy-backup`.

При запуске игры SWCH сначала переключает GALAXY на выбранный аккаунт, затем запускает установленную игру через `GalaxyClient.exe`, с отдельными аргументами `/command=runGame`, `/gameId` и `/path`. Неустановленные игры устанавливаются в официальном клиенте. Если GOG отозвал сохранённый доступ, подключи аккаунт заново через браузер.

Онлайн-библиотеки поддерживаются на всех платформах сборки SWCH. Переключение входа, автоматическое обнаружение установок и запуск игр через GALAXY реализованы для Windows; на macOS можно открыть обнаруженный клиент. Переключение входа и запуск игр на macOS и Linux пока недоступны.

## Нестандартная установка

- `SWCH_GOG_DIR`: папка клиента или путь к `GalaxyClient.exe`.
- `SWCH_GOG_GAMES_DIR`: дополнительные корневые папки с играми; на Windows разделитель — `;`. Манифесты ищутся на глубине до трёх уровней.
- `SWCH_GOG_REGISTRY_FILE`: текстовый экспорт `reg query ... /s`, используемый для локальных проверок.

## API

- `GET /api/gog/auth/url`, `POST /api/gog/auth/open`, `POST /api/gog/auth/login` (`code`).
- `GET /api/gog/accounts`, `POST /api/gog/switch-account`, `POST /api/gog/accounts/remove` (`account_id`).
- `GET /api/gog/library` (необязательный `account_id`), `POST /api/gog/library/sync` (необязательный `account_id` в JSON).
- `POST /api/gog/open-launcher`, `POST /api/gog/launch` (`app_id`, необязательный `account_id`).

Ошибки и ответы API не содержат кодов авторизации или токенов. Отключение аккаунта удаляет его сохранённый доступ и связи библиотеки из SWCH; остальные аккаунты и вход в GALAXY сохраняются.

Формат OAuth и API библиотеки проверен по [Heroic gogdl](https://github.com/Heroic-Games-Launcher/heroic-gogdl/blob/main/gogdl/auth.py) и [GOG-интеграции Heroic](https://github.com/Heroic-Games-Launcher/HeroicGamesLauncher/blob/main/src/backend/storeManagers/gog/library.ts). Аргументы запуска и форматы установок проверены по [GOG-интеграции Playnite](https://github.com/JosefNemec/PlayniteExtensions/blob/master/source/Libraries/GogLibrary/GogLibrary.cs).
