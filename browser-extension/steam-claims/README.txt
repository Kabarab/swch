SWCH — подключение магазина Steam для автоклеймера

1. Распакуйте ZIP в постоянную папку.
2. В Chrome откройте chrome://extensions (в Edge — edge://extensions).
3. Включите режим разработчика → «Загрузить распакованное расширение» → выберите эту папку.
4. В SWCH откройте вкладку мода «Раздачи игр» → «Аккаунты» → «Подключить магазин» у аккаунта Steam.
5. Откройте появившуюся ссылку в браузере с расширением.
6. Войдите на store.steampowered.com в выбранный аккаунт с «Запомнить меня» и нажмите «Подключить текущий вход Steam».
7. Повторите подключение для остальных аккаунтов.

Расширение читает только вход store.steampowered.com, только после нажатия кнопки
на странице подключения локального SWCH. Пароли не запрашиваются. Сессия хранится
в системном хранилище учётных данных и обновляется автоматически, пока сохранённый
вход разрешён Steam. Если Steam его отзовёт, потребуется повторный вход.
Не удаляйте папку расширения, пока оно установлено.
