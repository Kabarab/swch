# SWCH — вход в Epic Games через обычный браузер

Поддерживаются Chrome 112+, Edge и Brave на Windows и macOS. Установи расширение
в тот профиль браузера по умолчанию, где сохранены твои входы Google и пароли.

1. Открой `chrome://extensions` (Edge: `edge://extensions`, Brave: `brave://extensions`).
2. Включи «Режим разработчика».
3. Нажми «Загрузить распакованное расширение» и выбери эту папку `epic`.
4. В SWCH выбери «Добавить аккаунт» → Epic Games → «Войти в Epic Games».

SWCH откроет локальную страницу в браузере по умолчанию. Расширение откроет
обычное отдельное окно Epic в этом же профиле. Вход Google, регистрация,
двухфакторная проверка и автозаполнение работают средствами браузера и Epic.
После входа окно закроется, аккаунт появится в SWCH, библиотека загрузится в фоне.

Для другого Epic-аккаунта выбери другой аккаунт на странице Epic. Расширение
не очищает текущие входы браузера. Если Epic сразу возвращает уже добавленный
аккаунт, сначала выйди из Epic в этом браузере и повтори добавление.

Расширение не опубликовано в магазине; загрузка папки выполняется один раз.
Firefox и Safari в этой версии используют запасной способ — подключение по коду.
Подписанная публикация расширения в магазинах не выполняется автоматически.

## Какие данные доступны расширению

- Локальная страница `/epic/connect` на `127.0.0.1` или `localhost` инициирует вход.
- Только вкладка, открытая расширением для этой сессии, может передать результат.
- На `/id/api/redirect` Epic читается только JSON с `authorizationCode`.
- Одноразовая сессия SWCH действует 10 минут. Код передаётся локальному SWCH.
- Пароли, cookies и сохранённые входы Google расширение не читает.
- Привязка вкладки хранится в `storage.session`, очищается при закрытии браузера
  и после завершения входа. Результат входа хранит SWCH обычным способом.

Если SWCH перезапущен, вкладка закрыта или время истекло, начни вход заново.
Ручное подключение по коду всегда доступно в приложении.
