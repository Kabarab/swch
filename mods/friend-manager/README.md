# Менеджер друзей (Cross-Account Friend Manager) для SWCH

Мод для [SWCH](https://github.com/Kabarab/swch), объединяющий аккаунты для быстрого управления списками друзей:
1. **Взаимная дружба (Cross-Friending):** быстрое добавление в друзья между всеми зарегистрированными в SWCH аккаунтами в один клик.
2. **Пакетное удаление (Batch Unfriend):** удаление друзей сразу пачками с фильтрами по активности (>30, >90 дней) и поиском.
3. **Массовое добавление (Broadcast Invite):** отправка приглашения в друзья сразу со всех зарегистрированных аккаунтов (по коду друга/SteamID или клонирование из друзей другого аккаунта).
4. **Тема оформления:** встроенная кибер-тёмная тема для интерфейса SWCH (`theme.json`).
5. **Фоновые задания (Durable Jobs):** длительные сетевые операции выполняются через SDK Jobs с отображением прогресса, поддержкой отмены и сохранением контрольных точек (checkpoint) при перезапуске.

---

## Требования

- **SWCH** с поддержкой Mod SDK `^1.1.0`
- **Node.js 24 LTS** (для разработки и упаковки; для обычных пользователей Node.js уже встроен в SWCH)
- Платформы: Windows x64 (`windows-x64`), macOS Apple Silicon (`macos-arm64`)

## Разрешения и безопасность

- Серверная часть мода работает в процессе Node.js с правами пользователя.
- Ключи Steam Web API и сессионные куки сохраняются через `swch.secrets` в защищенном системном хранилище ОС (Windows DPAPI / macOS Keychain).
- Мод не собирает телеметрию, не передаёт учётные данные на сторонние серверы и взаимодействует только со Steam Web API / Steam Community при явном указании ключей.
- Без ключей доступа доступен полнофункциональный режим генерации протокольных команд `steam://friends/add/<id>` и локального кэширования.

---

## Настройки

- **Steam Web API Key:** позволяет загружать официальные списки друзей через Web API.
- **Steam Community Session Cookie:** позволяет отправлять прямые запросы добавления/удаления без открытия клиента Steam.
- **Задержка между запросами (мс):** предотвращает ошибку Rate Limit (429) при массовых операциях (по умолчанию 1200 мс).
- **Режим эмуляции:** позволяет протестировать всю функциональность локально без отправки сетевых запросов.

## Локальное тестирование и разработка

1. Запустите SWCH.
2. Перейдите в **Моды → Установка из ZIP и разработка → Подключить папку**.
3. Укажите абсолютный путь к папке мода:
   ```text
   E:\swch\mods\friend-manager
   ```
4. После редактирования файлов нажмите **Перезагрузить**.
5. Проверьте:
   - Включение и отключение мода;
   - Перезапуск SWCH с сохранением настроек и контрольных точек заданий;
   - Работу вкладки «Менеджер друзей» и кнопок действий на карточке мода.

## Публикация и обновление

1. Создайте публичный репозиторий в личном GitHub-аккаунте (организации не поддерживаются каталогом SWCH).
2. Загрузите файлы мода в репозиторий.
3. Укажите версию в `manifest.json` (например, `1.0.0`) и создайте тег:
   ```bash
   git tag v1.0.0
   git push origin v1.0.0
   ```
4. GitHub Actions автоматически соберёт и опубликует релиз с вложением `mod.zip`.
5. Перейдите в репозиторий [Kabarab/swch](https://github.com/Kabarab/swch) и откройте Issue по шаблону **Publish a SWCH mod**, указав `owner/repository`.
6. Для обновления выпустите новый тег (например, `v1.0.1`) с увеличенной версией в манифесте. Каталог обновляется каждые 6 часов.
