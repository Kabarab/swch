Магазины и расписание

В пробном режиме игры не добавляются в библиотеку.

Когда выключено, обычные проверки и расписание работают в фоне через API и скрытый браузер: SWCH не запускает управление Epic Launcher. При необходимости входа или CAPTCHA появится причина остановки; окно открывается только по отдельной кнопке. Для каждого аккаунта сохраняется отдельный профиль. При смене Chrome на Edge потребуется новый вход.

При отказе API SWCH попробует получить игру в окне Epic Launcher по сохранённому входу, если окна разрешены. В фоновом режиме этот способ запускается только кнопкой «Получить через Epic Launcher» у аккаунта. Нужен Windows OCR en-US и английский интерфейс магазина. Оставь окно в фокусе и не пользуйся мышью и клавиатурой во время оформления. Аккаунты могут переключаться; при запущенной игре, проверке безопасности или неясной цене получение остановится. Успех подтверждается лицензией.
