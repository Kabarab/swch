# Раздачи игр и автоклеймер SWCH

Единый мод `swch.autoclaimer`: каталог раздач, автоклеймер, вкладка «Раздачи игр»,
Node.js backend и нативный
процесс `swch-autoclaimer`. Основной сервер не запускает расписание и не
регистрирует `/api/free-games`. Выключение, удаление или завершение SWCH
закрывает процесс мода и нативный процесс, включая фоновые проверки.

Мод использует существующую базу SWCH и прежние ключи системного хранилища:
настройки, история лицензий, аккаунты и сохранённые входы сохраняются.
Удаление пакета не очищает эти данные.

Сборка из корня проекта:

```powershell
cargo build --release --bins
node scripts/build-autoclaimer-mod.mjs windows-x64 output/autoclaimer
```

Для macOS ARM64 укажи `macos-arm64` и путь к собранному `swch-autoclaimer`
третьим аргументом. ZIP содержит только бинарник целевой ОС. Установи его
через «Моды → Установка из ZIP». Релиз SWCH включает ZIP в `bundled-mods`:
мод появляется в каталоге доступных расширений. Установка выполняется кнопкой
«Установить» во вкладке «Моды → Каталог»; управление — в «Установленных».
После удаления он остаётся в каталоге и не устанавливается сам.

`ui.mjs`, `claim-state.mjs`, `view.html`, `style.css` — исходники интерфейса; сборщик
включает их вместе со стилями в один `index.html` для изолированного iframe.
Нативная точка входа — `native/main.rs`; общая реализация магазинов находится
в `src/auto_claim`, HTTP обработчики — в `src/server/auto_claim.rs`.
Каждый запуск использует случайный локальный порт и секретный токен,
недоступный iframe. Длительные операции опрашиваются через SDK без увеличения
общего таймаута других модов. Steam extension использует прежнюю одноразовую
привязку к конкретному аккаунту.
